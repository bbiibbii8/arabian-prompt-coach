# Prompt Coach

أنشئ موقعًا تفاعليًا عربيًا بالكامل باسم «طوّر برومبتك»، مخصصًا لفعالية أساسيات الذكاء الاصطناعي. تبدأ اللعبة بعرض الطلب الأصلي: «اشرح أساسيات الذكاء الاصطناعي». يكتب الطالب نسخة محسنة من الطلب في مربع نص، ويمكنه إضافة الجمهور المستهدف والأمثلة والتفاصيل والقيود وطريقة تنسيق الإجابة. عند الضغط على زر «قيّم التحسين»، اعرض: • البرومبت الأصلي والبرومبت المحسّن جنبًا إلى جنب. • درجة جودة كل برومبت من 100. • نسبة التحسن وفرق النقاط. • العناصر التي أضافها الطالب. • رسالة تشجيعية لطيفة وشخصية بحسب النتيجة. • اقتراحًا واحدًا يساعد الطالب على تحسين البرومبت أكثر. استخدم تصميمًا عصريًا لطيفًا بألوان بنفسجية وكحلية، وواجهة عربية من اليمين إلى اليسار، مع أزرار واضحة وحركات بسيطة. اجعل الموقع متجاوبًا مع الجوال والكمبيوتر. استخدم تقييمًا قائمًا على معايير واضحة، ولا تدّعِ قياس دقة إجابة الذكاء الاصطناعي دون اختبار مخرجات فعلية. لا تتطلب النسخة الأولى تسجيل دخول أو API مدفوعًا. أنشئ موقعًا يعمل فعلًا، وليس مجرد تصميم ثابت، وتأكد من أن جميع الأزرار والحسابات تعمل.
